# 👋 Houseo
> Houseo is a Real Estate UI template built by [cssninjaStudio](https://cssninja.io).

## ✌️ preview

Check out the live demo by clicking [here](https://houseo.cssninja.io/). 
Houseo is built with [Bulma](https://bulma.io) and [Alpine JS](https://github.com/alpinejs/alpine).

## 👍 Features

* Gulp 4 and nodejs 16.x (minimum)
* Bulma 0.9.x
* ES6 support
* Alpine v3.x

## 👌 Usage

1. Install Depedencies

```sh
pnpm i
```

2. Run in dev mode

```sh
pnpm dev
```

3. Or build source

```sh
pnpm build
```
